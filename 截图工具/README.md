# 截屏取码 → 粘贴工具 v2

用**微信截图**（或自带框选/复制监听）获取屏幕上的代码 → 自动 OCR 识别 → 文字进剪贴板 → 按「适配档」投递：普通应用自动切窗口粘贴，游戏走**安全模式**只放剪贴板由你手动 Ctrl+V。

## 🖥️ 房间码极速助手（图形界面版，推荐）

双击桌面的 **「房间码极速助手」快捷方式**（或 `启动房间码助手.bat`）打开纯图形界面，**无任何终端窗口**：

1. 点「**选择识别区域**」→ 框选直播画面中房间码的位置（坐标自动保存，与命令行版共用）。
2. 点「**开始识别**」→ 程序每 1 秒识别一次该区域。
3. **连续 2 帧识别到相同代码**才会复制（防单帧误识别）→ 复制成功时**发出声音提示**、状态变绿、代码显示在界面上 → 切到游戏按 **Ctrl+V**。
4. 「停止识别」或 **Ctrl+Alt+K**（任何界面下有效）紧急停止。

准确性保障：小图自动增强 + 干扰符号清洗 + **连续 N 帧确认**（`gui_confirm_frames` 可改成 3 更严格）+ 界面实时显示「待确认代码」和原始 OCR 文本，方便你核对。声音可用 `gui_sound: false` 关闭。

## 推荐工作流（一键截图，最快路径）

1. 双击 `启动工具.bat` 启动（默认就是 **VALORANT 安全模式** 档）。
2. 按 **F6**（可自定义）→ 直接弹出系统截图 → 拖拽框选代码 → **松开鼠标即完成**。
3. 工具约 30ms 内自动 OCR，识别文字**替换进剪贴板**（小图/模糊图会自动增强后再识别）。
4. 切到目标应用按 **Ctrl+V**。若当前适配档是微信/QQ（F7 切换），第 4 步自动完成。

> 也可以直接按 Win+Shift+S 或微信截图 Alt+A，效果相同（都是图片进剪贴板触发）。
> 微信没在运行时还可用 **F8**（工具自带全屏框选 OCR），或 **F9** 布防后 Ctrl+C 复制文字。

## 热键（全部可在 config.json 自定义，支持组合键如 `ctrl+alt+s`）

| 热键 | 功能 |
|------|------|
| **F2** | 框选并保存「直取区域」（原文复制功能用） |
| **F3** | 直取：识别直取区域的全部文字 → 原文直接进剪贴板 → 可直接粘贴 |
| **F4** | 开始/停止「区域监控」：持续识别监控区域，按正则提取代码（如房间码）并复制 |
| **F5** | 框选并保存监控区域（设置一次即可，坐标永久保存） |
| **F6** | 一键呼出系统截图（等效 Win+Shift+S），框选松开后自动识别 |
| **F7** | 循环切换适配档（VALORANT安全模式 → 微信 → QQ → 通用） |
| **F8** | 自带框选截屏 OCR（主显示器全屏，不依赖微信） |
| **F9** | 布防：下一次复制（文字或微信截图）后自动投递；再按一次取消 |
| **F10** | 立即处理当前剪贴板（是图片就 OCR，是文字就投递） |
| **F11** | 控制台列出所有可见窗口标题 |
| **F12** | 退出 |

## 🎯 两种区域功能（不同键位、不同用途）

**功能一：房间码提取（F5 设区域 + F4 监控）**——适合直播画面里持续显示的固定格式内容：

1. 按 **F5** → 框选代码显示的区域（如直播画面中「房间代码」那一栏）→ 自动保存坐标。
2. 按 **F4** 开始监控：工具每 1 秒截一次该区域 → OCR → 按正则提取代码 → **代码一变就自动复制到剪贴板**，你直接 Ctrl+V 粘贴。
3. 再按 **F4** 停止。

**功能二：区域直取（F2 设区域 + F3 一键复制）**——适合「把某块区域的文字原样复制走」：

1. 按 **F2** → 框选你想复制内容的区域 → 自动保存。
2. 需要时按 **F3**：工具识别该区域**全部文字（不做正则过滤）** → 原文进剪贴板 → 直接 Ctrl+V。

两个区域互相独立，可分别框在屏幕任意位置（选择框覆盖所有显示器，高分屏也已适配）。

提取规则在 config.json 里改（只影响功能一）：

```jsonc
{
  "region": null,                    // F5 框选后自动填入
  "region_direct": null,             // F2 框选后自动填入
  "region_monitor_interval": 1.0,    // 监控间隔（秒）
  "extract_pattern": "[A-Z0-9]{6}"   // 房间代码=6位大写字母+数字
}
```

- 想提取其他格式就改正则，例如 8 位码 `"[A-Z0-9]{8}"`、纯数字 `"[0-9]{6}"`。
- 同一代码不会重复复制；代码变化才会更新剪贴板并提示。
- 监控/直取期间工具只读屏幕像素，不向任何程序发送输入，安全模式不受影响。

## 🛡️ 无畏契约防封说明（重要）

反作弊（Vanguard）能检测的风险行为只有一类：**程序向游戏进程发送模拟按键/注入代码**。因此：

- **VALORANT 安全模式档 `auto_paste: false`：工具绝不激活游戏窗口、绝不发送任何模拟按键、绝不接触游戏进程**。它做的全部事情 = 把识别出的文字放进 Windows 剪贴板。之后的 Alt+Tab 切窗口和 Ctrl+V 都是你本人的真实按键，与反作弊无关，**风险为零**。
- 请**不要**给 VALORANT 档开启 `auto_paste` 或 `use_direct_input`——那是向游戏模拟按键，属于宏行为，有封号风险。工具无法替任何第三方反作弊系统「打包票」，但安全模式在设计上不存在可被检测的行为。
- 微信/QQ/浏览器/编辑器等普通应用没有反作弊，可放心用自动粘贴。

## 适配软件选项（profiles）

`config.json` 中每个应用一个适配档，**新增软件只需照抄一条**：

```jsonc
{
  "name": "钉钉",              // 显示名（F7 切换时显示）
  "target_window": "钉钉",     // 窗口标题关键字，F11 可查询
  "auto_paste": true,          // true=自动切窗口粘贴；false=安全模式(只放剪贴板)
  "use_direct_input": false,   // 普通应用一律 false；true 仅限无反作弊的 DirectX 程序
  "note": "备注说明"
}
```

- `active_profile`：当前生效的适配档序号（F7 切换后自动保存）。
- 带反作弊的游戏（VALORANT、CS2、PUBG 等）：一律 `auto_paste: false`。

## 其他配置项

```jsonc
{
  "watch_clipboard_image": "always",  // 截图监听：always=随时自动OCR / armed=仅F9布防后 / off=关闭
  "ocr_language": "en-US",            // 代码识别推荐 en-US；中文注释多改 "zh-Hans-CN" 或 "auto"
  "ocr_enhance": true,                // 小图/模糊图自动增强（放大+灰度+对比度），提高识别率
  "paste_delay": 0.15,                // 自动粘贴时，激活窗口后等几秒再按 Ctrl+V
  "clipboard_poll_interval": 0.03,    // 剪贴板轮询间隔（秒），30ms≈实时，检查本身零开销
  "ocr_warmup": true                  // 启动时预热 OCR 引擎，消除首次识别冷启动延迟
}
```

**速度**：截图进剪贴板 → 识别文本进剪贴板，实测端到端 **约 32ms**（OCR 本身 9~60ms，取决于截图大小）。
推荐用 **Win+Shift+S**（Windows 自带截图）：松开鼠标图片即进剪贴板，比微信截图少一次「✓」确认，且不依赖微信运行。
注意：全屏独占的游戏画面上 Win+Shift+S 可能弹不出来，需先切出游戏或用 F8。

## 常见问题

- **微信截图后没反应**：确认微信截图是「复制到剪贴板」模式（截图后点 ✓ 或双击即复制）；确认 `watch_clipboard_image` 不是 `off`；看控制台日志。
- **OCR 识别不准**：Windows 自带引擎对代码的标点偶有误差（如丢括号）。能选中复制的文字请用 F9 方式（零误差）；截图时字体越大越清晰越准。
- **自动粘贴不生效**：按 F11 核对 `target_window` 关键字；目标应用若以管理员权限运行，本工具也需管理员运行。
- **测试脚本**：`test_ocr.py`（OCR 引擎）、`test_clipboard_image.py`（微信截图链路，会覆盖剪贴板）、`test_smoke.py`（启动自检）。
